Qua 10 n ă m đ ã đă ng ký th ự c hi ệ n nhi ề u mô hình “ Dân v ậ n khéo ” , trong đ ó có nh ữ ng mô hình hi ệ u qu ả đượ c duy trì và nhân rộ ng, tiêu bi ể u có m ộ t s ố đ iể n hình tậ p th ể , cá nhân đ ã đượ c Trung ươ ng, T ỉnh u ỷ tặ ng b ằ ng khen, đ iể n hình nh ư : lĩnh v ự c kinh tế : Mô hình “ 1 ph ả i, 5 gi ả m ” trong s ả n xu ấ t lúa; tr ồ ng cây nha đ am, cây mãng c ầ u; tr ồ ng n ấ m bào ng ư xám ; ch ă n nuôi bò v ỗ béo; nuôi dê cái sinh s ả n; liên k ế t s ả n xu ấ t lúa gi ố ng; … Giai đ o ạ n 2025-2030 ti ế p tụ c tri ể n khai th ự c hi ệ n các mô hình, đ iể n hình dân v ậ n khéo, trong đ ó có nhi ề u mô hình đ ang tri ể n khai đạ t hi ệ u qu ả nh ư : mô hình “ C ử a hàng 0 đồ ng ” , mô hình “ Dân v ậ n khéo trong n ắ m b ắ t d ư lu ậ n xã h ộ i, đị nh h ướ ng tư tưở ng cán b ộ , đả ng viên ” , mô hình “ Th ắ p sáng đườ ng quê ”…
G ắ n thi đ ua v ớ i h ọ c tậ p và làm theo tư tưở ng, đạ o đứ c, phong cách H ồ Chí Minh , c án b ộ , công ch ứ c xã hàng n ă m đă ng ký vi ệ c h ọ c tậ p và làm theo Bác g ắ n v ớ i tu d ưỡ ng đạ o đứ c công v ụ , đổ i m ớ i tác phong làm vi ệ c theo h ướ ng "Tr ọ ng dân, g ầ n dân, hi ể u dân, h ọ c dân và có trách nhi ệ m v ớ i dân". Phát huy vai trò g ươ ng m ẫ u c ủ a ng ườ i đứ ng, th ủ tr ưở ng c ơ quan, đơ n v ị trong đố i tho ạ i và gi ả i quy ế t khó kh ă n cho nhân dân, coi đ ây là nhi ệ m v ụ  th ườ ng xuyên , tr ọ ng tâm.
Vi ệ c g ắ n k ế t ch ặ t ch ẽ gi ữ a phong trào "Dân v ậ n khéo" v ớ i h ọ c tậ p và làm theo Bác đ ã tạ o độ ng lự c để cán b ộ , công ch ứ c thay đổ i lề lố i làm vi ệ c từ "m ệ nh lệ nh hành chính" sang "v ậ n độ ng, thuy ế t ph ụ c". Đ iề u này không ch ỉ nâng cao hi ệ u lự c qu ả n lý nhà n ướ c mà còn góp ph ầ n xây d ự ng h ệ th ố ng chính tr ị c ơ s ở trong s ạ ch, v ữ ng m ạ nh.
7. Đ ánh giá tác độ ng c ủ a vi ệ c th ự c hi ệ n K ế t lu ậ n s ố 114-KL/TW đố i v ớ i công tác xây d ự ng Đả ng, Nhà n ướ c, c ủ ng c ố  ni ề m tin c ủ a Nhân dân 7.1. Nh ữ ng k ế t qu ả  đạ t đượ c Công tác xây d ự ng Đả ng và Nhà n ướ c:  Vi ệ c th ự c hi ệ n K ế t lu ậ n s ố 114- KL/TW, ngày 14/7/2015 c ủ a Ban Bí th ư (khóa XI) v ề nâng cao hi ệ u qu ả công tác dân v ậ n c ủ a c ơ quan nhà n ướ c các c ấ p đ ã giúp h ệ th ố ng chính tr ị từ xã đế n thôn chuy ể n bi ế n m ạ nh m ẽ nh ậ n th ứ c và hành độ ng . S ự lãnh đạ o , ch ỉ đạ o sâu sát c ủ a Th ườ ng tr ự c Đả ng ủ y và công tác qu ả n lý, đ iề u hành tr ự c ti ế p c ủ a Ủ y ban nhân dân xã đượ c nâng lên , thông qua vi ệ c c ụ th ể hóa thành ch ươ ng trình hành độ ng, k ế ho ạ ch tri ể n khai th ự c hi ệ n các ch ế độ chính sách an sinh xã h ộ i, các ch ươ ng trình m ụ c tiêu gi ả m nghèo c ủ a nhà n ướ c , trong đ ó có chính sách h ỗ tr ợ vùng đồ ng bào dân tộ c thi ể u s ố ; công tác tôn giáo. Độ i ng ũ cán b ộ , công ch ứ c tác phong chu ẩ n m ự c, tinh th ầ n trách nhi ệ m, đổ i m ớ i ph ươ ng th ứ c làm vi ệ c, g ầ n dân, tậ n tụ y ph ụ c v ụ nhân dân; tă ng c ườ ng công tác tuyên truy ề n, v ậ n độ ng nhân 9 dân th ự c hi ệ n các chính sách c ủ a nhà n ướ c, ch ươ ng trình m ụ c tiêu qu ố c gia v ề gi ả m nghèo và xây d ự ng nông thôn m ớ i.
M ặ t tr ậ n T ổ qu ố c, các tổ ch ứ c chính tr ị xã h ộ i không ng ừ ng đổ i m ớ i n ộ i d ung, ph ươ ng th ứ c ho ạ t độ ng, là lự c lượ ng nòng c ố t trong công tác v ậ n độ ng Nhân dân th ự c hi ệ n các ch ủ tr ươ ng, đườ ng lố i c ủ a Đả ng, chính sách, pháp lu ậ t c ủ a Nhà n ướ c; huy đ ộ ng, tậ p h ợ p h ộ i viên, đ oàn viên và các tầ ng lớ p Nhân dân tạ o thành s ứ c m ạ nh tổ ng h ợ p đ oàn k ế t các dân tộ c, tôn giáo p hát huy tố t vai trò giám sát, ph ả n bi ệ n xã h ộ i và tham gia góp ý xây d ự ng Đả ng, xây d ự ng chính quy ề n.
C ủ ng c ố ni ề m tin c ủ a Nhân dân:  Nh ờ th ự c hi ệ n tố t quy ch ế dân ch ủ ở c ơ s ở , các chính sách h ỗ tr ợ c ủ a nhà n ướ c trên đị a bàn xã ở các lĩnh v ự c kinh tế -xã h ộ i, an sinh xã h ộ i… đượ c bình xét công khai, minh b ạ ch, đ úng đố i tượ ng .
